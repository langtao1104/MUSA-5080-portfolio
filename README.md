# Lang Tao — MUSA 5080 Portfolio

| 位置 | 用途 |
|---|---|
| `assignments/assignment2.qmd` 至 `assignment5.qmd` | 作业源文件，在这里修改 |
| `assignments/assignment5/` | A5 预测 CSV 和小组分工说明 |
| `data/` | 原始数据，保持原样 |
| `weekly-notes/` | 每周笔记 |
| `Practice/` | 练习文件，不参与网站构建 |
| `docs/` | 自动生成的 GitHub Pages 网页 |
| `_freeze/` | Quarto 执行缓存，保留以便重复构建 |

在 RStudio 打开 `MUSA-5080-portfolio.Rproj`，修改 QMD 后保存并 Render，再 Commit 和 Push。

网站：[MUSA 5080 Portfolio](https://langtao1104.github.io/MUSA-5080-portfolio/)。
